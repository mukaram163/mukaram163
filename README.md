## ⭐ Featured project

### [Enterprise RAG Agent](https://github.com/mukaram163/enterprise-rag-agent)
Permission-aware question answering over Google Drive PDFs with page-level citations.
- Hybrid retrieval: PostgreSQL/pgvector + BM25, merged with Reciprocal Rank Fusion, then a cross-encoder reranker
- Per-document access control checked in the database on every search
- Single-agent and multi-agent modes over an MCP search server
- Evaluation harness that found a chunk-size retrieval problem; page expansion raised coverage from 0.65 to 0.92 on 6 test questions (small sample, results and limits in the README)
